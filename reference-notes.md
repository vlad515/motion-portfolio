# Ориентиры для переработки

## Видеорил

Видеорил Влада Коченкова «Motion Designer Showreel 2025» длится 57 секунд. Для сайта применяются только общие принципы его подачи: чистый нейтральный фон, один яркий цвет на сцене, тактильные физические материалы, масштабные фрагменты объекта, плотный ритм смены состояний и крупный гротеск. Контент и отдельные кадры рила не копируются.

## Фирменный знак

В предоставленном изображении присутствует белое кольцо, чёрный скруглённый кошачий силуэт, белая линия ушей и две синие точки. По явному указанию пользователя этот образ используется как знак в шапке и фавиконе; сгенерированная иконка исключается из сайта.
